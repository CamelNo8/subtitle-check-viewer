1. 目的

仕様設計書の未確認事項「広告の再生中・広告明けに、YouTubeが返す再生時刻が本編の時刻のままか」を確かめる。あわせて、YouTube のプレイヤーが返す値のどれかで広告を自動で見分けられそうかも調べる。

  • 問い1: 広告中、プレイヤーが返す再生時刻はどうなるか（止まる・0になる・広告の時刻になる など）
  • 問い2: 広告明けに、再生時刻は本編の場面と合っているか（F3の字幕表示がずれないか）
  • 問い3: 状態・動画の長さ・動画IDのどれかが、広告の間だけ変わるか（自動で見分けられるか）

2. 決まったこと（質問への回答）

項目決定
調査に使う動画実験で使う動画。URLは調査時に画面へ貼るので、仕様書には書かない
広告の答え合わせプログラムでは広告を直接見分けられない（動画の枠の中は外から覗けない）ため、Mac標準の画面収録（Cmd+Shift+5）で調査ページごと録画し、あとで目で確かめる。「広告開始／終了」ボタンは置かない

3. ファイル構成

research/
├── ad-timing.html   # 調査ページ（URL欄・今の値・変化の一覧）
└── ad-timing.js     # 0.25秒ごとに値を調べ、表示と一覧の追加を行う

F1 の部品を使い回す: extractVideoId（URL→動画ID）、loadYoutubeApi（APIの読み込み）、describePlayerError（エラー文言）。 再生時刻などを読むためにプレイヤー本体が必要なので、プレイヤーは調査ページの中で直接作る（F1 の showVideo は変えない）。

4. 調査ページの仕様

4.1 画面

┌─────────────────────────────────────────────────────┐
│ YouTube URL [__________________] [読込]                │
├───────────────────────────┬─────────────────────────┤
│                           │ 経過時間   123.45 秒       │
│      YouTube動画           │ 再生時刻    98.250 秒      │
│                           │ 状態       再生中          │
│                           │ 動画の長さ  1420.5 秒      │
│                           │ 動画ID     xxxxxxxxxxx    │
├───────────────────────────┴─────────────────────────┤
│ 変化の一覧（新しい順）                                   │
│ 経過時間 | 再生時刻 | 出来事                             │
│ 123.45  | 98.250  | 状態: バッファ中 → 再生中            │
│ 118.20  |  0.000  | 動画の長さ: 1420.5 → 15.0           │
└─────────────────────────────────────────────────────┘
  • 録画であとから読めるよう、今の値は大きめの文字で表示する
  • 経過時間: 「読込」を押してからの実際の時間（ページの時計。YouTube に頼らない）。録画の場面と一覧を突き合わせる目印にする
  • 再生時刻: プレイヤーが返す時刻（getCurrentTime）。小数3桁まで
  • 状態: 未開始 / 終了 / 再生中 / 一時停止 / バッファ中 / 頭出し済み を日本語で表示
  • 動画の長さ: getDuration。広告中に広告の長さに変わるかを見る
  • 動画ID: getVideoData().video_id。広告中に入れ替わるかを見る

4.2 変化の一覧に載せる出来事

0.25秒ごとに値を調べ、次のときだけ1行追加する（毎回載せると一覧がすぐ埋まって読めないため）。

出来事条件
状態の変化状態が前回と違う
動画の長さの変化動画の長さが前回と違う
動画IDの変化動画IDが前回と違う
時刻の飛び「再生時刻の進み」と「経過時間の進み」の差が0.5秒を超えた（シーク・広告明けの巻き戻りなど）
時刻が進まない状態が「再生中」なのに、再生時刻が1秒以上変わらない（広告中に本編の時刻が止まっている可能性）。進み始めたら「時刻が進み始めた」を1行追加
プレイヤーのエラーF1 と同じ文言

5. 調査の手順（研究者）

  1. Chrome のシークレットウィンドウを開く（YouTube Premium のログインや広告ブロック拡張があると広告が流れないため）
  2. 簡易サーバーを起動し、http://localhost:8000/research/ad-timing.html を開く
  3. Cmd+Shift+5 で画面収録を始める（動画と右側の値、下の一覧が入る範囲）
  4. 実験で使う動画のURLを貼って「読込」→ 再生する
  5. 次の場面をそれぞれ録画する
    • 再生開始前の広告（プレロール）
    • 途中の広告（ミッドロール。動画が長い場合）
    • 途中の広告の位置をまたいでシークしたとき
  6. 録画を止め、変化の一覧の画面をスクリーンショットで残す
  7. 録画を見返し、6章の表に「広告が映っていた経過時間」と「そのときの値」を記入する（Claude が記入を手伝う）

広告は毎回流れるとは限らないため、流れなかったときはページを再読み込みして繰り返す。
