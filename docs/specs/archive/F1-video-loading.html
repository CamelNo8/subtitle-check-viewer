1. 目的

YouTubeのURLを入力して「読込」を押すと、画面の左側に埋め込みプレイヤーが表示され、動画を再生できるようにする。 字幕・一覧・CSVなど他の機能は後のステップで作る。

4. 部品の仕様

4.1 extractVideoId(url: string): string（src/youtube-url.js）

YouTubeのURL文字列から、11文字の動画IDを取り出して返す。

  • 前後の空白は取り除いてから判定する（コピペで空白が入りやすいため）
  • 受け付けるホスト: youtube.com / www.youtube.com / m.youtube.com / youtu.be
  • &t=30s、&list=...、?si=... などの余分な部分は無視してIDだけ返す
  • 動画IDは「英数字・-・_ の11文字」のときだけ正しいとみなす
  • 読み取れないときは Error を投げる。原因ごとに別のメッセージにする（下表）。空欄以外はメッセージに入力値を含める
原因例メッセージ（案）
空欄空文字・空白だけYouTubeのURLを入力してください。
URLの形になっていないabc、https:// が無いURLとして読み取れません: 「○○」。YouTubeの動画ページのアドレス欄にあるURL（https:// から始まるもの）をそのまま貼り付けてください。
YouTube以外のURLhttps://vimeo.com/123YouTube以外のURLです: 「○○」。youtube.com または youtu.be のURLを貼り付けてください。
YouTubeのURLだが、動画を指していないhttps://www.youtube.com/watch（v= が無い）、チャンネルページ、トップページ動画のURLではありません: 「○○」。見たい動画を開いた状態のURL（例: https://www.youtube.com/watch?v=xxxxxxxxxxx）を貼り付けてください。
動画IDの形がおかしいIDが10文字・12文字、使えない記号が入っている（コピーの途中切れなど）URLの動画ID「○○」が正しくありません（英数字と - _ の11文字のはずです）。URLが途中で切れていないか確認し、もう一度コピーしてください。
文字列以外が渡されたnull などTypeError「URLは文字列で渡してください（受け取った型: ○○）」。プログラムの誤りなので企業の方には通常出ない

4.2 describePlayerError(code: number): string（src/player-error-message.js）

YouTubeプレイヤーが返すエラー番号を、企業の方が読んで対処できる日本語に変える。 設計書の最大のリスク「埋め込み禁止の動画は再生できない」を画面で分かるようにするため。

コード意味（YouTube公式）表示するメッセージ（案）
2パラメータが不正YouTubeが動画IDを受け付けませんでした。URLをもう一度コピーして貼り付けてください。（エラーコード: 2）
5HTML5プレイヤーのエラーブラウザで動画を再生できませんでした。ページを再読み込みしてください。直らない場合は Chrome など別のブラウザでお試しください。（エラーコード: 5）
100動画が見つからない（削除・非公開）動画が見つかりません。削除または非公開になった可能性があります。研究者に連絡してください。（エラーコード: 100）
101動画の所有者が埋め込み再生を許可していないこの動画は、所有者が他のサイトでの再生を許可していないため再生できません。研究者に連絡してください。（エラーコード: 101）
150101と同じ（YouTube公式では同じ意味。年齢制限や、存在しない動画でも出ることがある）この動画は、埋め込み禁止・年齢制限などの設定、または削除・非公開により、他のサイトでは再生できません。研究者に連絡してください。（エラーコード: 150）
上記以外—原因不明のエラーで動画を再生できませんでした。研究者に連絡してください。（エラーコード: ○○）

どのメッセージにもエラーコードを付け、企業の方から連絡を受けたときに原因を特定できるようにする。

テストするケース: 上表の各コード（2・5・100・101・150）でそれぞれのメッセージが返ること（正常系）、表に無いコード（例: 999）で「原因不明」のメッセージにそのコードが入ること（異常系）、数値以外（undefined など）で TypeError になること（異常系）。

4.3 youtube-player.js（外部とのやりとり）

  • loadYoutubeApi(): Promise<void> — IFrame Player API のスクリプト（https://www.youtube.com/iframe_api）を1回だけ読み込み、準備ができたら完了する。 失敗の原因ごとに別のメッセージで失敗する（外部との通信にはタイムアウトを付ける規約のため、15秒で打ち切る）
    原因メッセージ（案）
    スクリプトの読み込みに失敗（オフライン、社内ネットワークでYouTubeが遮断されている など） YouTubeに接続できませんでした。インターネット接続を確認してください。社内ネットワークでYouTubeが制限されている場合は、社内の管理者にご確認ください。
    15秒以内に準備ができない（回線が遅い・YouTube側の一時的な不調） YouTubeのプレイヤーの準備に時間がかかりすぎたため中止しました。しばらく待ってからページを再読み込みしてください。
  • showVideo(elementId, videoId, onError): Promise<void> — 1回目はプレイヤーを作り、2回目以降は同じプレイヤーで動画を差し替える（cueVideoById＝読み込むだけで自動再生はしない）。エラー時は onError(code) を呼ぶ
  • 後のステップ（F3・F4）で再生時刻の取得と移動が必要になるが、それは F3・F4 で追加する（今は作らない）

このファイルはYouTube（外部）とのやりとりだけなので、自動テストは書かずブラウザで確認する（規約1.4：外部とのやりとりはロジックと分ける）。 判断が必要な処理（URL解析・エラー文言）は 4.1・4.2 に切り出してテストする。

5. 動かし方

  • 最初に1回: npm install（ESLint・Prettier を入れる）
  • テスト: npm test
  • リンタ: npm run lint ／ 見た目の確認: npm run format:check ／ 見た目を整える: npm run format
  • 画面確認: ESモジュールはHTMLのダブルクリックでは動かないため、簡易サーバーで開く
    uv run --no-project python -m http.server 8000 → ブラウザで http://localhost:8000

6. 確認してほしい点

  • 4.1〜4.3 のエラーメッセージの文言。原因ごとに別のメッセージにし、企業の方が自分で直せるもの（URLの貼り間違い・通信・ブラウザ）は直し方を、研究者しか直せないもの（削除・埋め込み禁止・原因不明）は「研究者に連絡」を案内する方針。

7. 実装中に決めたこと

  • Prettier の1行の長さを100文字に設定（.prettierrc.json）。コーディング規約の目安「1行100文字くらい」に合わせるため
  • フォームに novalidate を付けた。ブラウザ独自のURLチェックが先に動くと、4.1 のメッセージが表示されないため
  • ローカル確認用の起動設定 .claude/launch.json を追加
