1. 目的

読み込んだ全字幕を動画の右側に一覧で表示する。行をクリックするとその字幕の開始時刻へ移動し、再生中の字幕の行を色で目立たせる。 設計書の「区間の繰り返し再生」は作らず、このジャンプで代用する。

2. 決まったこと（質問への回答）

項目決定
一覧の時刻当面は SRT の時刻のまま（00:01:02,345）。F7 でタイムコードに置き換える
一覧の列番号・開始時刻・字幕（設計書の画面どおり。コメント・修正案は F5 で追加）
選択 or ドラッグの枠一覧を出したら一覧の上に1行の小さな枠として残す（読み込み直し用）。右側の欄全体へのドラッグも今までどおり受け付ける
自動スクロール一覧の上に「再生位置に追従」のチェックを置く（最初は ON）。ON のときだけ、今の行が見えなくなったら一覧をスクロールする
クリックで移動した後今の状態のまま（再生中なら続けて再生、止まっていれば止まったまま）

3. 画面

┌──────────────────────────┬───────────────────────────────┐
│                          │ [ SRTファイルを選択 or ドラッグ ]  │ ← 1行の小さな枠
│       YouTube動画        │ ドラえもん.srt: 387件… ・警告     │
│                          │ ☑ 再生位置に追従                  │
│                          │ 番号 開始          字幕           │
├──────────────────────────┤  1  00:00:00,000  ドラえもん登場…  │
│  （ドラえもん）…          │▶ 2  00:00:04,177  未来の国から…   │ ← 今の行は色つき
└──────────────────────────┴───────────────────────────────┘
                                  ↑ 一覧だけがスクロールする（欄の高さは動画＋字幕欄と同じ）
  • 一覧の字幕はタグを消した文字で表示し、色はつけない（白い背景で黄色などが読めなくなるため）。改行はそのまま改行する
  • 本文が空の字幕は、灰色で「（本文なし）」と表示する
  • 今の字幕の行は背景色を変える。時間が重なっているときは両方の行を強調する
  • 行のどこをクリックしても移動する。キーボードでも操作できるよう、開始時刻をボタンにする（Tab で選んで Enter）
  • 動画を読み込む前に行をクリックしたら、動画のメッセージ欄に「先に YouTube の URL を貼り付けてください。」と出す
  • SRT の読み込みがエラーになったら一覧を消し、選択の枠を大きな表示に戻す
  • 画面の横幅が 900px より狭いときは、右側の欄を動画の下に並べ（1列）、欄の高さを画面の高さの 60% にする。警告は3行ほどの高さまでにして、それ以上は警告の中でスクロールする（実装中に追加: 狭い画面で読み込み結果と警告が欄の高さを使い切り、一覧が見えなくなったため）

5. 部品の仕様

5.1 formatSrtTime(ms: number): string（src/srt-time-format.js）

種別入力結果
正常系6234500:01:02,345
正常系3723004（1時間2分3秒4ミリ秒）01:02:03,004
境界値000:00:00,000
異常系負の数RangeError
異常系整数でない（1.5、NaN）・数値でないTypeError

5.2 calculateScrollTop(row, view): number | null（src/scroll-position.js）

row = { top, height }（一覧の中での行の位置）、view = { scrollTop, height }（今のスクロール位置と見えている高さ）。 行が全部見えていれば null（動かさない）。上にはみ出していれば行の上端を、下にはみ出していれば行の下端を見える範囲に合わせるスクロール位置を返す。

種別入力結果
正常系行が見える範囲の中null
正常系行が見える範囲より下行の下端が見える範囲の下端に来る位置
正常系行が見える範囲より上行の上端の位置
境界値行の下端が見える範囲の下端ちょうどnull
境界値行が見える範囲より高い行の上端の位置（上端を優先して見せる）
異常系数値でない値を含むTypeError

5.3 seekToMs(ms: number): boolean（src/youtube-player.js に追加）

  • 指定の時刻へ移動する。まだ動画を表示していなければ何もせず false を返す
  • 再生中・バッファ中・一時停止中: seekTo で移動する（一時停止中は止まったまま。ブラウザで確認済み）
  • 未再生・頭出し済み・再生終了: 開始時刻付きで頭出しをやり直す（cueVideoById({ videoId, startSeconds })）。止まったままで、再生時刻も移動先になる。
    実装中に変更（2026-09-26）: 当初は「seekTo の後に一時停止」の予定だったが、ブラウザで試すと未再生の状態では seekTo が予約されるだけで、2回目以降の移動が再生時刻に反映されず、字幕欄と一覧が古い字幕のまま残った。頭出しのやり直しなら毎回正しく反映されることを確認した
  • 制約: 未再生のまま移動したときは、動画の画面にはその場面ではなくサムネイルが出る（再生すると移動先から始まる）。字幕欄・一覧は移動先の字幕を示す
  • YouTube とのやりとりなので自動テストは書かず、ブラウザで確認する

5.4 一覧の描画（src/subtitle-list.js）

  • renderSubtitleList(tableBody, subtitles): 行を作り直す（SRT を読み込んだときだけ呼ぶ）
  • highlightSubtitleRows(tableBody, subtitles, activeSubtitles): 今の行の強調を付け替え、強調した最初の行の要素を返す（追従のスクロールに使う）。行と字幕を対応させるため、一覧を作ったときの subtitles も受け取る（実装中に引数を追加）
  • 字幕の文字は textContent で入れる（HTML として解釈させない）。タグの除去は F3 の parseSubtitleMarkup を使い回す
