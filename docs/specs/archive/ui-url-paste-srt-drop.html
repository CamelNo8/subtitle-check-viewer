1. 決まったこと（質問への回答）

項目決定
URL の読み込みURL 欄に貼り付けたら自動で読み込む。「読込」ボタンは消す。手で打ち込んだ場合は Enter で読み込む
SRT の置き場所操作欄から外し、動画の右側（字幕一覧を表示する場所）全体を SRT の場所にする
SRT の選び方その場所をクリックするとファイル選択、ファイルをドラッグして落としても読み込める。表示は「SRTファイルを選択 or ドラッグ」。「SRT」のラベルは消す
.srt 以外が落とされたエラーで知らせ、読み込まない

2. 画面

┌──────────────────────────────────────────────────┐
│ YouTube URL [______________________________]        │ ← 貼り付けで自動読み込み
├────────────────────────────┬─────────────────────┤
│                            │ ┌ ─ ─ ─ ─ ─ ─ ─ ─ ┐ │
│                            │   SRTファイルを選択   │
│       YouTube動画          │   or ドラッグ          │ ← この範囲全体に
│                            │                      │    ドラッグできる
│                            │ └ ─ ─ ─ ─ ─ ─ ─ ─ ┘ │
│                            │ 283件の字幕を読み込みました │
│                            │ ・48番: 終了時刻が…     │
└────────────────────────────┴─────────────────────┘
  • 右側の欄は動画と同じ高さ。点線の枠は、その下の結果表示の分を除いた高さいっぱいに広げる。ファイルをドラッグして欄の上に来たら枠の色を変えて、落とせることを示す
  • ドラッグは点線の枠だけでなく、右側の欄全体（枠の下の結果表示の上を含む）で受け付ける（「範囲全部」の指示に合わせて実装中に変更）
  • 読み込み結果（件数・警告・エラー）は枠の下に表示する。選んだファイル名も結果の文に入れる（例:「ドラえもん.srt: 387件の字幕を読み込みました」）
  • 枠の外にファイルを落としても何もしない（ブラウザがファイルを開いて画面が切り替わらないようにする）
  • F4 で字幕一覧を作るとき、この場所に一覧を表示する。一覧表示後の「選択 or ドラッグ」の見せ方は F4 の仕様で決める

3. 部品の仕様

pickSrtFile(files: File[]): File（src/srt-file-picker.js）

ドラッグ・選択されたファイルの中から、読み込む SRT ファイルを1つ返す。ファイル名だけで判断する（中身は F2 の parseSrt が確かめる）。

種別入力結果
正常系字幕.srt 1つそのファイル
正常系字幕.SRT（大文字）1つそのファイル
境界値0個エラー「ファイルが選ばれていません。」
異常系動画.mp4 1つエラー「SRT ファイル（.srt）を選んでください:「動画.mp4」」
異常系2つ以上エラー「SRT ファイルは1つだけ選んでください（2個選ばれています）。」
異常系配列以外TypeError

貼り付け・ドラッグのイベント処理はブラウザの機能なので main.js に置き、ブラウザで確認する。
