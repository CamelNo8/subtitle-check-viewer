1. 目的

パソコン内の SRT ファイルを選ぶと、字幕の一覧（番号・開始時刻・終了時刻・本文）としてアプリに読み込む。 F2 では読み込みと件数・警告・エラーの表示までを作る。字幕の表示（F3）・一覧（F4）は後のステップ。

2. 決まったこと（質問への回答）

項目決定
形の崩れた字幕（番号・時刻の行が読めない）読み込みを止めてエラー表示。どの字幕か（番号・何番目か）と直し方を示す
UTF-8 以外のファイルエラーで知らせる（文字化けしたまま読み込まない）
読み込めたときの表示「○件の字幕を読み込みました」
本文が空の字幕空の字幕として読み込む
終了が開始より前・長さ0秒読み込んで警告を出す（チェックの対象なので止めない）
番号の飛び・重複飛びは問題なし。重複はエラー（CSV 再開時に番号で字幕を探すため区別できない）
テストの材料実SRTはリポジトリに入れない（番組の書き起こしのため）。実SRTの形を再現した短い見本をテスト内に書く

5. 部品の仕様

5.1 decodeUtf8(bytes: ArrayBuffer | Uint8Array): string（src/utf8-decoder.js）

  • UTF-8 として読み、文字列を返す。先頭の BOM は取り除く
  • UTF-8 として正しくないバイトがあれば Error「文字コードが UTF-8 ではないため読み込めません。字幕ファイルを UTF-8 で保存し直してください。」
種別入力結果
正常系UTF-8 の日本語そのままの文字列
正常系BOM 付き UTF-8BOM を除いた文字列
境界値0バイト空文字
異常系Shift_JIS の日本語UTF-8 ではないエラー
異常系バイト列以外（文字列など）TypeError

5.2 parseSrt(text: string): { subtitles, warnings }（src/srt-parser.js）

戻り値:

  • subtitles: { number, startMs, endMs, text } の配列（ファイルの順番どおり）
    • number: SRT の字幕番号（整数）
    • startMs / endMs: 開始・終了時刻（ミリ秒の整数）。フレームへの変換は F7 で行う
    • text: 本文。複数行は改行（\n）でつなぐ。タグ・空白は元のまま。本文なしは空文字
  • warnings: 警告メッセージの配列（例:「48番: 終了時刻が開始時刻より前です」）

読み方:

  • 先頭の BOM を取り除き、改行コード CRLF・CR は LF にそろえる（Windows で保存し直された場合に備える）
  • 空行（空白だけの行を含む）で字幕のまとまりに分ける。空行が2つ以上続いてもよい
  • まとまりの1行目が番号、2行目が時刻（00:00:01,000 --> 00:00:03,500）、3行目以降が本文
種別入力結果
正常系字幕1件番号・時刻（ミリ秒）・本文が取れる
正常系字幕が複数件件数とファイル順が合う
正常系本文が2行改行でつながった本文
正常系<font color="#FFFF00"> 付きの本文タグを残したままの本文
正常系BOM 付きの文字列1件目の番号が正しく読める
正常系改行が CRLF本文に \r が残らない
正常系字幕の間の空行が2つ余分な字幕ができない
正常系番号の飛び（128 → 130）エラーにも警告にもならない
境界値本文が空（番号・時刻だけ）本文が空文字の字幕として読める
境界値開始と終了が同じ読み込み、警告「○番: 表示時間が0秒です」
境界値終了が開始より前読み込み、警告「○番: 終了時刻が開始時刻より前です」
境界値空文字・空行だけエラー「字幕が1件もありません。SRT ファイルの中身を確認してください。」
異常系番号の行が数字でないエラー「○番目の字幕の番号が読めません:「…」。」
異常系時刻の行が崩れている（（森本）00:04:45,580 --> 00:04:50,29）エラー「85番の字幕の時刻が読めません:「…」。「00:00:01,000 --> 00:00:03,500」の形に直してください。」
異常系時刻の分・秒が60以上時刻が読めないエラー
異常系番号の後に時刻の行がない時刻が読めないエラー
異常系同じ番号が2回エラー「字幕番号 ○ が重複しています。SRT の番号が重ならないように直してください。」
異常系文字列以外TypeError

  • SRT のファイル選択（.srt のみ表示）は YouTube URL の「読込」ボタンの右隣に置く。結果の表示欄はその下の行に置く（F1 の動画用メッセージとは別の欄）。2026-09-26 クライアントの指示で変更（当初は操作欄の2行目）

  • エラー: 赤字でエラーメッセージとファイル名を出す。前に読み込んだ字幕の表示は消す（2026-09-26 F5 で変更: エラーのときは前の字幕・一覧・コメントを残す。F5-review-input.html 参照）
  • 読み込んだ字幕は F3・F4 で使うときに保持する仕組みを作る（F2 では件数と警告の表示だけ）

6. 実装中に分かったこと・決めたこと

  • ファイルが改行で終わると、最後の字幕の本文に余分な改行が残る不具合をテスト（CRLF のケース）が見つけた。字幕のまとまりの前後の改行を取り除いて修正（実SRT 14件はすべて改行で終わるため、実際に起きる不具合だった）
  • SRT の選択欄を YouTube URL の「読込」の右隣へ移した（クライアントの指示）。結果の表示は下の行。画面が狭いと SRT 欄は次の行に回り込む。1280px 幅で同じ行に並ぶこと、狭い幅で横にはみ出さないことをブラウザで確認
