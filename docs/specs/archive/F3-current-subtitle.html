1. 目的

再生中の時刻に合う字幕を、動画のすぐ下の黒い字幕欄に表示する。字幕の位置が気にならないよう、動画には重ねない。

2. 決まったこと（質問への回答）

項目決定
字幕の時間が重なっているとき両方を上下に並べる（番号の順に上から）
<font color> 以外のタグ（<b> <i> など）タグを消して文字だけ出す
受け付ける色の書き方#RRGGBB の形だけ（大文字・小文字どちらでも）。それ以外は白
字幕欄の文字の大きさ動画の幅に合わせて変える（動画が大きいほど文字も大きい）。ただし最小 16px（2026-09-26 クライアント承認。狭い画面で 8px 台になり読みにくかったため）

3. 表示のルール

  • 字幕は「開始時刻 ≦ 再生時刻 ＜ 終了時刻」のときに表示する（終了時刻ちょうどでは消える。一般的な SRT の扱いと同じ）
  • 終了が開始より前、長さ0秒の字幕（F2 で警告を出すもの）は表示されない
  • 表示する字幕がない時間、SRT を読み込んでいないとき、動画を読み込んでいないときは空欄
  • 本文の改行はそのまま改行して表示する。（名前） や効果音の文字も普通の文字として表示する
  • SRT を読み込み直したら新しい字幕に切り替える。SRT の読み込みがエラーになったら字幕を消す
  • 字幕の文字は必ず「文字」として画面に入れる（HTML として解釈させない）。SRT に変な文字列が入っていても画面が壊れないようにするため

4. 画面

  • 字幕欄は動画と同じ幅。字幕がないときも2行分の高さを取っておく（字幕が出るたびに下の要素が上下に動かないように）。重なりで3行以上になったら欄が伸びる
  • 文字の大きさは動画の幅に比例させる（CSS のコンテナ単位 cqw を使う。今のブラウザはすべて対応）。ただし 16px より小さくはしない

6. 部品の仕様

6.1 findActiveSubtitles(subtitles, timeMs): Subtitle[]（src/active-subtitles.js）

F2 の parseSrt が返した字幕の一覧から、timeMs（ミリ秒）に表示すべき字幕をファイル順（番号の順）で返す。

種別入力結果
正常系字幕の途中の時刻その字幕1件
正常系2件が重なる時刻2件（ファイル順）
正常系字幕と字幕の間の時刻空の配列
境界値開始時刻ちょうどその字幕を含む
境界値終了時刻ちょうどその字幕を含まない
境界値長さ0秒の字幕の時刻含まない
境界値終了が開始より前の字幕どの時刻でも含まない
境界値字幕が0件空の配列
異常系時刻が数値でない（NaN を含む）TypeError
異常系字幕が配列でないTypeError

6.2 parseSubtitleMarkup(text): Segment[][]（src/subtitle-markup.js）

本文を行ごとに分け、各行を「文字のかたまり { text, color }」の配列にする。color は #RRGGBB か、指定なし（白で表示）を表す null。

種別入力結果
正常系こんにちは[[{text:"こんにちは", color:null}]]
正常系<font color="#FFFF00">こんにちは</font>[[{text:"こんにちは", color:"#FFFF00"}]]
正常系色つきと色なしが1行に混在（（三上）<font color="#00FFFF">平和だな</font>）2つのかたまり（色なし・色つき）
正常系2行の本文2行
正常系色タグの中で改行している両方の行が同じ色
正常系<b> <i> などのタグタグを消した文字だけ
正常系色の小文字（#ffff00）、シングルクォート（color='#FFFF00'）その色
境界値空文字空の配列（何も表示しない）
異常系#RRGGBB 以外の色（yellow、#FF0）色なし（null）
異常系</font> の閉じ忘れ本文の最後まで同じ色
異常系対応する開きタグのない </font>無視する
異常系タグではない <（例: 3 < 5）そのまま文字として残す
異常系文字列以外TypeError

6.3 getCurrentTimeMs(): number | null（src/youtube-player.js に追加）

プレイヤーの再生時刻をミリ秒で返す。まだ動画を読み込んでいなければ null。YouTube とのやりとりなので自動テストは書かず、ブラウザで確認する。

6.4 画面の更新（src/main.js）

  • ブラウザの描画のたび（requestAnimationFrame、1秒に約60回）に再生時刻を読み、表示すべき字幕が変わったときだけ字幕欄を描き直す
  • 再生中でも一時停止中でも、シークした直後でも、そのときの時刻の字幕を出す

7. リスクと確認

  • YouTube のプレイヤーが返す再生時刻がどのくらいの間隔で更新されるかは、公式資料に書かれていない。ToDo 7 で実際に測り、結果を8章に書く。更新が粗くて字幕の切り替えが目に見えて遅れる場合は、経過時間で補う方法（補間）をクライアントに相談してから追加する
  • 広告中の再生時刻の扱いは、保留中の調査（ad-timing-research.html）で確かめる

確認内容結果
