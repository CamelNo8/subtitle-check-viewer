1. 目的

字幕一覧の各行に「コメント（指摘）」と「修正案」を書けるようにする。字幕そのもの（本文・時刻）はアプリでは直さない（設計書どおり）。 書いた内容の保存（CSV 書き出し）と再開（CSV 読み込み）は F6 で作る。

2. 決まったこと（質問への回答）

項目決定
入力欄の形複数行を書ける欄。Enter で改行でき、書いた分だけ欄が高くなる
入力欄の配置各行の字幕の下に「コメント」「修正案」を縦に並べる（右側の欄の幅は今のまま）
消えないための対策コメント・修正案が1件でもあるときに、ページを閉じる・再読み込みする・別の SRT を読み込むと確認を出す
入力中の追従入力欄にカーソルがある間は「再生位置に追従」のスクロールを休む（行の強調は続ける）。入力欄から出たら、次に字幕が切り替わったときから追従を再開する

3. 画面

番号 開始          字幕
 12  00:00:30,983  （ドラえもん・のび太）ふん
                   コメント [表示時間が短い                 ]
                   修正案   [（ドラえもん・のび太）ふんっ    ]
                            [                               ] ← 改行すると欄が伸びる
  • 入力欄にはそれぞれ「コメント」「修正案」の見出しを付ける（どちらの欄か分かるように）
  • 入力欄や見出しをクリックしても動画は移動しない（書くたびに動画が飛ばないように）。番号・開始時刻・字幕の文字をクリックしたときだけ移動する
  • コメント・修正案のどちらかが書かれている行は、番号の横に印（●）を付けて、書いた行が一覧で分かるようにする
  • 空白だけの入力は「書かれていない」とみなす（確認や印の判断で）。入力された文字そのものは変えずに記録する

4. 消える前の確認

操作書かれた字幕が1件以上あるとき
ページを閉じる・再読み込みするブラウザ標準の「このサイトを離れますか？」の確認を出す（文言はブラウザが決めるため変えられない）
別の SRT を読み込む（選択・ドラッグ）読み込みに成功したあと、差し替える前に「書いたコメント・修正案（○件）は消えます。新しい SRT に切り替えますか？」と確認する。「キャンセル」なら今の一覧とコメントをそのまま残す

F6 で CSV に書き出したあとは確認を出さないようにする（「書き出してから変更があるか」の判断は F6 で作る）。

変更の提案（承認をお願いします）: 今は、SRT の読み込みがエラーになると一覧を消している（F2・F4 で決めた動き）。 コメントを書けるようになると、読み込み直しに失敗しただけで書いたコメントが全部消えてしまう。 そこで F5 からは、読み込みがエラーになったら今の一覧とコメントをそのまま残し、エラーだけを表示するように変える。

6. 部品の仕様（src/reviews.js）

記録は「字幕番号 → { comment, suggestion }」のオブジェクト。元の記録は書き換えず、新しい記録を返す。

6.1 updateReview(reviews, number, field, value): Reviews

種別入力結果
正常系空の記録に、12番のコメント「短い」{ 12: { comment: "短い", suggestion: "" } }
正常系12番のコメントがある記録に、12番の修正案コメントは残ったまま修正案が入る
正常系改行を含む修正案改行ごと記録される
正常系更新したとき元の記録は変わらない
境界値空文字で上書き空文字として記録される
異常系欄の名前が comment / suggestion 以外Error（プログラムの誤り）
異常系番号が整数でないTypeError
異常系値が文字列でないTypeError

6.2 countReviewedSubtitles(reviews): number

種別入力結果
正常系コメントだけの字幕1件・修正案だけの字幕1件2
正常系1件の字幕にコメントと修正案の両方1
境界値空の記録0
境界値空白・改行だけの入力数えない
境界値書いた後に消して空文字に戻した数えない

6.3 isReviewed(review): boolean

1件分の記録にコメント・修正案のどちらかが（空白以外で）書かれていれば true。一覧の「書いた印」に使う。6.2 の数え上げもこれを使う。
